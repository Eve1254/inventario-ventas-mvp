# Aplicación Windows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar instalador y ZIP Windows x64 del MVP, descargables desde GitHub.

**Architecture:** Separar la ruta de SQLite según ejecución fuente o empaquetada. PyInstaller genera un directorio autocontenido y un script de construcción prepara ZIP, instalador Inno Setup y sumas SHA-256.

**Tech Stack:** Python 3.14, Tkinter, SQLite, PyInstaller 6.22.3, Inno Setup.

**Spec:** docs/superpowers/specs/2026-10-30-windows-design.md

## Global Constraints

- Windows x64, interfaz existente, sin Python instalado por el usuario final.
- Conservar `data/inventario.db` al ejecutar desde fuentes.
- Ejecutable: `%LOCALAPPDATA%/InventarioVentas/inventario.db`; nunca incluir datos personales.
- No cambiar las reglas de venta ni de importación.
- Mantener datos al reinstalar o desinstalar; no añadir actualización automática.

## Review Focus

- Ruta temporal o instalación de solo lectura: la base debe vivir fuera del bundle.
- Variables de entorno ausentes/relativas y rutas con espacios/acentos.
- Reinicio y sustitución del programa sin pérdida de datos.
- Artefactos sin base local, secretos, entorno de desarrollo ni archivos de pruebas.
- Instalación y eliminación por usuario sin borrar SQLite; documentación honesta de límites.
