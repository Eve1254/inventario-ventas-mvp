# Día 1: base de datos y primera ventana — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Entregar una ventana Tkinter que consulte productos de SQLite, con entorno local, pruebas y explicación para la sustentación.

**Architecture:** `database.py` posee conexiones y esquema; `inventory.py` expone la consulta; `ui.py` presenta los resultados. `main.py` inicia la aplicación y `demo.py` carga ejemplos únicamente bajo una acción explícita.

**Tech Stack:** Python 3.14.3 comprobado, Tkinter/ttk, sqlite3, pathlib, unittest; sin dependencias externas.

**Spec:** `docs/superpowers/specs/2026-10-28-inventario-pos-design.md`, aprobado. Este plan implementa únicamente el Día 1 solicitado.

## Global Constraints

- Aplicación local en un equipo, con una base SQLite guardada en `data/inventario.db` dentro del proyecto.
- Precio estrictamente positivo; stock entero mayor o igual a cero.
- Los precios son enteros de unidades monetarias mínimas; nunca usar float para dinero.
- Interfaz y documentación en español; base de datos y entorno virtual excluidos de Git.
- Tabla usuarios sin credenciales predeterminadas; el acceso no pertenece a esta etapa.
- Ventas, CRUD, alertas y CSV se implementarán en las etapas posteriores.

## Review Focus

- Ejecutar desde otro directorio debe conservar la misma ruta absoluta de base de datos: prueba `test_default_path_is_relative_to_project`.
- Volver a inicializar o cargar ejemplos no debe borrar ni sobrescribir datos: pruebas de persistencia e idempotencia.
- SQLite debe rechazar fracciones en stock y precio, además de valores negativos: prueba parametrizada de restricciones.
- Una lectura fallida debe mantener la tabla anterior y notificar el error: prueba de actualización fallida en la interfaz.
- Una lista vacía y nombres con tildes deben verse correctamente: prueba de integración de Tkinter y recorrido visual.

## Tarea 1: persistencia y consulta

**Files:** crear `.gitignore`, `app/__init__.py`, `app/database.py`, `app/inventory.py`, `app/demo.py`, `tests/__init__.py`, `tests/test_database.py` y `tests/test_inventory.py`.

**Interfaces:**
- `DEFAULT_DB_PATH: Path`: ruta absoluta a `data/inventario.db` relativa a los archivos fuente.
- `connect_db(db_path: Path = DEFAULT_DB_PATH)`: administrador de contexto que entrega `sqlite3.Connection`, activa claves foráneas, devuelve filas `sqlite3.Row`, confirma/deshace cambios y cierra la conexión.
- `initialize_database(db_path: Path = DEFAULT_DB_PATH) -> None`: crea directorios y tablas productos y usuarios si no existen.
- `list_products(db_path: Path = DEFAULT_DB_PATH) -> list[sqlite3.Row]`: consulta por nombre y luego id.
- `seed_demo_products(db_path: Path = DEFAULT_DB_PATH) -> int`: inicializa y agrega cinco productos de ejemplo sin modificar códigos existentes; devuelve cantidad insertada.
